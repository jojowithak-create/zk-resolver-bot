\# ⚡ ZKResolver (`zk-resolver-bot`)



> \*\*Autonomous, zero-knowledge, deterministic market resolution engine powering trustless settlement for binary event prediction markets.\*\*



\[!\[License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

\[!\[Rust](https://img.shields.io/badge/Rust-1.80%2B-orange.svg)](https://www.rust-lang.org/)

\[!\[Node.js](https://img.shields.io/badge/Node.js-v20%2B-green.svg)](https://nodejs.org/)

\[!\[Network: Base](https://img.shields.io/badge/Network-Base%20Mainnet-blue.svg)](https://base.org)



ZKResolver is an automated relayer and prover system that monitors decentralized and centralized prediction markets (Polymarket, Kalshi), fetches canonical resolution data from official off-chain API endpoints (e.g., SEC EDGAR, Federal Reserve), and generates zero-knowledge cryptographic proofs of state transitions. 



By bypassing slow human resolution committees and multi-sig multisigs, ZKResolver enables sub-second, cryptographically verified market settlements on Base.
